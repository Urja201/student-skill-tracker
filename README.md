# Student Skill Tracker

A beginner-friendly web application for students to track their skills, projects, and learning goals in one place.

## ✨ Features

- 👤 Student profile
- 💻 Skill tracking
- 📊 Skill progress levels
- ✏️ Add, edit and delete skills
- 🔎 Search and filter skills
- 📁 Project tracker
- 🎯 Learning goals
- 📅 Goal deadlines and progress
- 🏆 Achievements
- 🌙 Dark mode
- 💾 Data stored using LocalStorage

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub
- LocalStorage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## 📌 Project Purpose

This project was created as a learning project to practice frontend web development, JavaScript, Git, and GitHub while building a useful student productivity tool.
